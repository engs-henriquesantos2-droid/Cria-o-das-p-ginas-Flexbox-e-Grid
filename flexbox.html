O que é Flexbox?

Flexbox é um recurso do CSS usado para organizar elementos dentro de um contêiner. Ele ajuda a colocar caixas em uma linha ou coluna e controlar o alinhamento e o espaço entre elas.

Para usar Flexbox, colocamos display: flex; no elemento que contém as caixas.

1. Exemplo básico

As três caixas abaixo estão lado a lado porque o contêiner usa display: flex;.

1
2
3
.container {
    display: flex;
}

2. Direção dos elementos

A propriedade flex-direction define a direção das caixas.

  • row: coloca as caixas em uma linha.
  • column: coloca as caixas em uma coluna.
.container {
    display: flex;
    flex-direction: row;
}

3. Alinhamento e espaço

Algumas propriedades importantes:

  • justify-content: organiza os elementos no eixo principal, por exemplo, no começo, no centro ou com espaço entre eles.
  • align-items: alinha os elementos no eixo transversal.
  • gap: cria um espaço entre as caixas.
A
B
C
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 10px;
}

4. Quebra de linha

Com flex-wrap: wrap;, as caixas podem passar para a linha de baixo quando não existe espaço suficiente.

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 10px;
}

Dica: Flexbox é muito útil para menus, botões, barras de navegação e para alinhar elementos.

Atividade prática

Crie um contêiner com três caixas. Experimente mudar justify-content para center, space-between e flex-end. Observe como as caixas mudam de posição.
