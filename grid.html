O que é CSS Grid?

CSS Grid é um recurso do CSS que permite organizar elementos em uma grade, usando linhas e colunas. Ele é útil para criar layouts de páginas, galerias de imagens e conjuntos de cartões.

Para começar, usamos display: grid; no contêiner dos elementos. Depois, podemos definir a quantidade de colunas, o tamanho das linhas e o espaço entre os itens.

Com essas propriedades, conseguimos organizar o conteúdo de forma mais clara e adaptar a disposição dos elementos ao espaço disponível.

1. Exemplo básico de CSS Grid

Neste exemplo, vamos organizar seis elementos em três colunas. O CSS Grid permite controlar a posição dos itens e o espaço entre eles.

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}

grid-template-columns define as colunas. repeat(3, 1fr) cria três colunas com o mesmo tamanho. gap define o espaço entre os itens.

2. Linhas e colunas

As colunas organizam os itens na vertical e as linhas organizam os itens na horizontal. Quando uma linha fica cheia, os próximos itens passam para a linha seguinte.

Também podemos definir linhas usando grid-template-rows.

.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
    grid-template-rows: 100px 100px;
}

Nesse exemplo, a grade tem duas colunas iguais e duas linhas de 100 pixels.

3. Espaçamento entre os itens

A propriedade gap cria espaço entre linhas e colunas.

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

4. Onde usar Grid?

  • Galerias de fotos.
  • Cartões de produtos.
  • Divisão da página em áreas.
  • Organização de conteúdo em linhas e colunas.

Dica: Flexbox costuma ser prático para organizar elementos em uma direção. Grid é muito útil quando precisamos controlar linhas e colunas ao mesmo tempo.

Atividade prática

Altere repeat(3, 1fr) para repeat(2, 1fr) no exemplo e veja como os seis itens passam a ocupar duas colunas.
